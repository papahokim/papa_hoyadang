1 Executive Summary

본 백서는 재개발 1년 남은 낙후된 빵집을 콘텐츠 비즈니스의 실험실로 전환하는 전략을 문서화한다.

핵심 철학: 확장이 아닌 최적화, 매출 극대화가 아닌 생존, 매장이 아닌 콘텐츠 랩

"좌표는 찍혔다. 이제 손님을 부르기만 하면 된다."

7 D2P 커머스 아키텍처

D2P (Direct to Platform) 정의

자체 결제 시스템의 리스크(이탈률, 보안, 유지보수)를 배제하고, 대형 플랫폼의 결제 인프라를 100% 활용하는 모델

3단계 고객 여정 (The Funnel)

단계채널목적
Step 1: 유입 YouTube 미끼 — 시각적 자극으로 호기심 유발
Step 2: 설득 자사 홈페이지 팬덤 — 브랜드 가치/철학 전달, 가격 저항 제거
Step 3: 전환 배달 플랫폼 3사 원터치 패스 — Universal Link로 결제 유도

이중 가격제 (Dual Pricing)

정책: 배달 앱 판매가 = 매장 가격 + (플랫폼 수수료 + 배달비)

논리: Step 2(홈페이지)에서의 브랜딩 효과로 추가 비용을 '프리미엄 지불 의사'로 전환

8 기술 구현 사양

핵심 원칙

복잡한 딥링크 로직 = 폐기
각 앱의 공식 공유 링크 (Universal Link)만 사용

플랫폼별 마스터 링크

플랫폼공식 공유 URL
쿠팡이츠 https://web.coupangeats.com/share?storeId=550712
배달의민족 https://s.baemin.com/d2000gCVdxUak
요기요 https://ws.yogiyo.co.kr/jnsce1

구현 코드

function openCoupangEats() {
  location.href = 'https://web.coupangeats.com/share?storeId=550712';
}

function openBaemin() {
  location.href = 'https://s.baemin.com/d2000gCVdxUak';
}

function openYogiyo() {
  location.href = 'https://ws.yogiyo.co.kr/jnsce1';
}

이 방식의 장점

  • 카카오톡/인스타그램 호환 - 인앱 브라우저에서도 정상 작동
  • 유지보수 불필요 - 플랫폼 앱 업데이트와 무관하게 영구 유효
  • 자동 Fallback - 앱 없으면 자동으로 앱스토어 이동 (플랫폼 자체 기능)

최종 결론

"각 앱에서 직접 '공유하기 → 링크 복사' = 정답.
앱사가 만든 공식 공유 링크가 만능 열쇠.
앱 있으면 앱 열리고, 없으면 스토어로 알아서 감.
개발자가 건드릴 필요 없음."
