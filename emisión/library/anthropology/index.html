THESIS

손맛의 인류학

인간은 왜 손으로 만드는가. 아기는 손으로 먹고, 어머니는 손으로 빚고,
장인은 손끝으로 전한다. Amasar는 인간의 원시 프로토콜.

요리의 손맛 = 완전한 몰입
재료 + 손놀림 = 상호 교감의 과정

침묵의 인류학

요리는 말하지 않는다. 재료만 있고, 손만 있다.
이것은 언어 이전의 소통. 본능의 영역.

레시피 → 준비 → 조리 → ...
요리: 반죽 → 침묵 → 손 → 완성

역할의 인류학

리드와 팔로우. 이것은 젠더가 아니다.
제안과 수용. 질문과 응답. 권력이 아닌 대화.

Leader = 방향을 제안하는 사람
Follower = 제안을 해석하는 사람
둘 다 능동적. 둘 다 창조적.

KEY CONCEPTS

Conexión 두 손이 하나의 맛을 공유
Intención 움직이기 전의 에너지 전달
Escucha 재료의 소리를 듣는 것
Entrega 자기를 내어주는 것
Presencia 지금 여기에 완전히 존재
