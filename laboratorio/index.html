TECHNIQUE ENGINE v1.0

TECHNIQUE 001

Amasar

기본 움직임. 손으로 그리는 무한 도형. 반죽.

앞으로, 뒤로. 회전과 함께.
{ type: "figure", beats: 4, pivot: true }

TECHNIQUE 002

Cortar

의식적인 칼질. 끝내기가 아닌 느끼기 위한 자르기.

손으로 연결. 무게 전체 이동.
{ type: "locomotion", beats: 2, connection: "hands" }

TECHNIQUE 003

Reposar

힘이 아닌 인내로 멈추게 하기. 손이 "기다려"라고 말한다.

인내 필요. 1박.
{ type: "interruption", beats: 1, requires: "patience" }

TECHNIQUE 004

Rellenar

빈 공간을 맛으로 채우기. 밀지 않고.

에너지 전이. 속 채우기.
{ type: "displacement", beats: 2, energy: "transfer" }

TECHNIQUE 005

Volcán

통제된 폭발. 신뢰가 맛이 되는 순간.

공유 축. 신뢰 필수.
{ type: "off-axis", beats: 3, trust: "required" }

TECHNIQUE 006

Freír

담그기. 빠르고, 정확하고, 바삭하게.

폭발적 에너지. 기름 감싸기.
{ type: "hook", beats: 1, energy: "explosive" }

TECHNIQUE 007

Flamear

놓아버린 불꽃. 공중에서 해방되는 에너지.

원형 모멘텀. 손목에서 시작.
{ type: "whip", beats: 2, momentum: "circular" }

TECHNIQUE 008

Emplatar

접시 위에 놓기. 밀지 않고 안내하며.

손 대 접시. 부드러운 힘.
{ type: "sweep", beats: 2, force: "gentle" }
