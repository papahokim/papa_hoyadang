## Executive Summary

```
현재: 80개 메뉴 + 배달 의존 + 1인 운영 = 구조적 모순
제안: 15개 메뉴 + 직접 판매 + 프리미엄 = 지속 가능
```

## 1. 현재 문제 진단

### 1.1 구조적 모순

```
1인 운영 + 80개 메뉴 + 배달 플랫폼 의존
= 망하는 공식
```

### 1.2 문제 상세

| 요소 | 문제 |
|------|------|
| **80개 메뉴** | 재고 관리 불가, 품질 일정 안 됨, 조리 시간 증가 |
| **배달 플랫폼** | 수수료 15~30%, 마진 다 뺏김 |
| **1인 운영** | 주문 폭주하면 품질 저하 → 리뷰 악화 → 망함 |
| **가격 경쟁** | 평촌에서 저가로 버티기 = 자살 |

### 1.3 플랫폼 수수료 현실

| 플랫폼 | 수수료 | 실제 영향 |
|--------|--------|-----------|
| 배달의민족 | 15~20% + 광고비 | 실질 25~30% |
| 쿠팡이츠 | 15~20% | 15~20% |
| 요기요 | 12~15% | 12~15% |

**예시:**
```
파스타 15,000원 판매 시
├── 플랫폼 수수료 (25%): -3,750원
├── 재료비 (30%): -4,500원
├── 포장비: -500원
└── 실제 수익: 6,250원

→ 마진율 41% (플랫폼)
→ 마진율 66% (직접 판매)
```

## 5. 채널 전략

### 5.1 채널 비중 목표

| 채널 | 현재 (추정) | 목표 | 이유 |
|------|-------------|------|------|
| 매장 직접 | 30% | **60%** | 마진 100%, 품질 통제 |
| 포장 | 20% | **30%** | 마진 100%, 시간 통제 |
| 배달 | 50% | **10%** | 신규 고객 유입용만 |

### 5.2 배달 플랫폼 활용법

```
배민/쿠팡이츠 = "광고판"으로만 사용

전략:
1. 플랫폼에 메뉴 노출 (신규 고객 발견)
2. "전화/방문 주문 시 10% 할인" 안내
3. 직접 채널로 전환 유도
4. 단골화

플랫폼 → 직접 전환율 목표: 30%
```

### 5.3 직접 주문 유도 방법

| 방법 | 실행 |
|------|------|
| 가격 차별 | 직접 주문 10% 할인 |
| 쿠폰 | 방문 시 다음 방문 쿠폰 |
| 카카오톡 | 단골 고객 채널 운영 |
| 전화 예약 | "예약 고객 우선 제공" |

## 6. 생산량 통제

### 6.1 1인 한계 분석

```
현실적 처리량:
├── 점심 (11:30~14:00): 최대 20명
├── 저녁 (17:30~20:30): 최대 20명
└── 총: 40명/일

무리하면:
├── 품질 저하
├── 리뷰 악화
├── 체력 고갈
└── 지속 불가능
```

### 6.2 한정 수량 전략

```
"오늘의 한정 수량"

점심: 15세트
저녁: 15세트
─────────────
총: 30세트/일

효과:
1. 희소성 → 가치 상승
2. 체력 관리 → 지속 가능
3. 품질 유지 → 리뷰 관리
4. "품절" = 마케팅
```

### 6.3 예약 시스템

```
"예약 고객 우선"

카카오톡/전화 예약 → 확정
워크인 → 남은 수량만

→ 예측 가능한 운영
→ 재료 낭비 최소화
→ 단골 우대 → 충성도
```

## 7. 수익 시뮬레이션

### 7.1 목표 설정

```
월 최소 생계비: 250만원
목표 순수익: 300~350만원
```

### 7.2 일일 매출 시나리오

**보수적 (하루 25명)**
```
세트A (22,000원) × 10 = 220,000원
세트B (11,000원) × 5 = 55,000원
단품 (15,000원) × 5 = 75,000원
음료 (3,000원) × 10 = 30,000원
고로케 (4,000원) × 10 = 40,000원
─────────────────────────────────
일 매출: 420,000원
```

**현실적 (하루 30명)**
```
세트A (22,000원) × 12 = 264,000원
세트B (11,000원) × 6 = 66,000원
단품 (15,000원) × 6 = 90,000원
음료 (3,000원) × 15 = 45,000원
고로케 (4,000원) × 15 = 60,000원
─────────────────────────────────
일 매출: 525,000원
```

### 7.3 월간 손익 계산

**현실적 시나리오 기준**

```
월 매출: 525,000 × 25일 = 13,125,000원

비용:
├── 재료비 (30%): 3,937,500원
├── 임대료: 1,500,000원 (평촌 추정)
├── 공과금/가스: 400,000원
├── 소모품/포장: 200,000원
├── 배달 수수료 (10% 채널, 25%): 328,000원
├── 카드 수수료 (2%): 262,500원
└── 기타: 200,000원
─────────────────────────────────
총 비용: 6,828,000원

월 순수익: 6,297,000원
```

### 7.4 시나리오 비교

| 시나리오 | 일 고객 | 월 매출 | 월 순수익 |
|----------|---------|---------|-----------|
| 최악 | 20명 | 8,400,000 | 3,200,000 |
| 보수적 | 25명 | 10,500,000 | 4,700,000 |
| 현실적 | 30명 | 13,125,000 | 6,300,000 |
| 최대 | 40명 | 17,500,000 | 8,500,000 |

**결론:** 하루 20~30명이면 충분히 생계 + 여유 가능

## 9. 리스크 및 대응

### 9.1 예상 리스크

| 리스크 | 확률 | 대응 |
|--------|------|------|
| 가격 인상 → 고객 이탈 | 중 | 품질 강화, 단골 유지 |
| 메뉴 축소 → 불만 | 중 | "시그니처 집중" 설명 |
| 배달 매출 감소 | 높음 | 직접 채널 보완 (목표) |
| 한정 수량 → 기회 손실 | 낮음 | "품절 = 가치" 포지셔닝 |

### 9.2 실패 시 롤백

```
만약 3개월 후 매출 30% 이상 감소 시:
1. 인기 삭제 메뉴 2~3개 복원
2. 가격 일부 조정
3. 배달 비중 재검토

핵심: 데이터 기반 의사결정
→ POS 데이터 주간 체크
```

## 10. 핵심 철학

### 10.1 패러다임 전환

```
❌ "많이 팔아서 버는 구조"
   → 1인 운영 불가능
   → 품질 저하 필연
   → 체력 고갈

✅ "적게 팔고 많이 남기는 구조"
   → 1인 운영 가능
   → 품질 유지
   → 지속 가능
```

### 10.2 평촌 시장 포지셔닝

```
평촌 = 안양의 부촌

싸게 팔면:
→ "싼 집" 이미지 고착
→ 가격 올리기 어려움
→ 마진 압박 지속

처음부터 프리미엄으로:
→ "비싸지만 맛있는 집"
→ 단골 형성
→ 가격 저항 낮음
```

### 10.3 20년의 가치

```
"20년 손맛"은 마케팅 문구가 아님.
실제 자산임.

이걸 3,000원 고로케로 팔면:
→ 가치 훼손

이걸 4,000원 "장인의 고로케"로 팔면:
→ 가치 실현
```
