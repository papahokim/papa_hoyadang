## 호야당 BGM 철학

```
아저씨 취향 = 정답

K-라틴 퓨전이 컨셉에 맞아도
아저씨가 좋아하는 음악이 진정성.

철학보다 진정성.
개념보다 사람.
```

— CLAUDE.md §8 참조 (Feels So Good — Chuck Mangione과 같은 맥락)

### 왜 이 컬렉션이 어울리나

| 이유 | 설명 |
|------|------|
| 따뜻한 클래식 | 야상곡, 트로이메라이, 세레나데, 사랑의 꿈 — 주방의 온기와 맞음 |
| 익숙한 멜로디 | 누구나 한 번쯤 들어본 곡 — 80% 철학과 일치 |
| 피아노 + 클라 + 첼로 | 다양성 있으면서 통일감 |
| 아저씨 선곡 | 직접 고른 곡 = 진정성 |
