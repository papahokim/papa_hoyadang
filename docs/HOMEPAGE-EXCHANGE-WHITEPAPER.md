# Homepage Exchange Business

> 워드프레스를 GitHub Pages로. 호스팅비 0원, 유지보수는 AI로.

**Version:** 1.0
**Date:** 2026-02-03
**Author:** parksy (dtslib)
**Case Study:** hoyadang.com

---

## Executive Summary

### 한 문장 정의
```
기존 워드프레스/카페24 사이트를 GitHub Pages 기반 정적 사이트로 전환하고,
결제/예약은 플랫폼에 위임하며, 유지보수는 AI(Claude Code)로 처리하는 서비스.
```

### 핵심 가치
| Before | After |
|--------|-------|
| 월 호스팅비 | 0원 (GitHub Pages 무료) |
| 보안 취약점 | 없음 (정적 사이트) |
| 플러그인 업데이트 | 불필요 |
| 수정하려면 코딩/외주 | 말로 지시 (AI) |
| 느린 로딩 | 빠름 (CDN 자동) |

## 1. 문제 정의

### 1.1 현재 소상공인 웹사이트 현황

**과잉 솔루션 문제:**
```
동네 빵집에 워드프레스?
= 탱크 몰고 편의점 가는 격

필요한 것:
- 메뉴판
- 위치
- 연락처
- 주문 링크

워드프레스가 제공하는 것:
- 데이터베이스
- 회원 시스템
- 플러그인 생태계
- 관리자 대시보드
- ... (안 쓰는 기능 90%)
```

**비용 구조:**
| 항목 | 월 비용 | 연 비용 |
|------|---------|---------|
| 호스팅 (카페24 등) | 5,000~30,000원 | 60,000~360,000원 |
| 도메인 | - | 15,000~30,000원 |
| SSL 인증서 | 0~10,000원 | 0~120,000원 |
| 테마/플러그인 | 0~50,000원 | 0~600,000원 |
| 유지보수 외주 | 50,000~200,000원 | 600,000~2,400,000원 |
| **합계** | | **675,000~3,510,000원** |

**보안 리스크:**
- 워드프레스 = 전 세계 해커의 타겟 1순위
- 플러그인 취약점 → 사이트 해킹
- 업데이트 안 하면 → 악성코드 감염
- 소상공인은 이거 모름 → 방치

### 1.2 플랫폼 경제의 부상

**결제/예약 인프라 완성:**
```
2015년: 자체 결제 시스템 필요
2020년: 배민/쿠팡이츠 입점하면 끝
2025년: 네이버예약, 카카오예약, 토스 결제

→ 웹사이트가 결제를 처리할 필요 없음
→ 웹사이트 = 브랜딩 + 트래픽 허브 역할만
```

**플랫폼 목록:**
| 카테고리 | 플랫폼 |
|----------|--------|
| 음식 배달 | 배달의민족, 쿠팡이츠, 요기요 |
| 예약 | 네이버예약, 카카오예약, 테이블링 |
| 결제 | 토스페이, 카카오페이, 네이버페이 |
| 커머스 | 스마트스토어, 29cm, 무신사 |
| 클래스 | 클래스101, 탈잉, 숨고 |
| 펀딩 | 텀블벅, 와디즈 |

## 2. 솔루션: Homepage Exchange

### 2.1 아키텍처

```
┌─────────────────────────────────────────────────────────┐
│                    사용자 (고객)                         │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│              GitHub Pages (정적 사이트)                  │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐     │
│  │  index.html │  │  menu.html  │  │  about.html │     │
│  │  (랜딩)     │  │  (메뉴판)   │  │  (소개)     │     │
│  └─────────────┘  └─────────────┘  └─────────────┘     │
│                                                         │
│  호스팅비: 0원 | SSL: 자동 | CDN: 자동                   │
└─────────────────────────────────────────────────────────┘
                          │
            ┌─────────────┼─────────────┐
            ▼             ▼             ▼
     ┌───────────┐ ┌───────────┐ ┌───────────┐
     │ 배달의민족 │ │ 쿠팡이츠  │ │ 네이버예약 │
     │ (배달)    │ │ (배달)    │ │ (예약)    │
     └───────────┘ └───────────┘ └───────────┘
           │             │             │
           └─────────────┼─────────────┘
                         ▼
              ┌─────────────────┐
              │   결제 처리     │
              │ (플랫폼이 담당) │
              └─────────────────┘
```

### 2.2 기술 스택

| 레이어 | 기술 | 비용 |
|--------|------|------|
| 호스팅 | GitHub Pages | 무료 |
| 도메인 | 기존 도메인 유지 | 연 15,000원 |
| SSL | GitHub 자동 제공 | 무료 |
| CDN | GitHub 자동 제공 | 무료 |
| 버전 관리 | Git | 무료 |
| 유지보수 | Claude Code | API 비용 (미미) |

### 2.3 유지보수 프로세스

**기존 방식:**
```
사장님: "메뉴 가격 바꿔주세요"
    ↓
외주 업체 연락 (1일)
    ↓
견적 (50,000원~)
    ↓
수정 완료 (2~3일)
    ↓
총 소요: 3~4일, 50,000원+
```

**Homepage Exchange 방식:**
```
사장님: "메뉴 가격 바꿔줘"
    ↓
Claude Code 실행
    ↓
"파스타 15,000원으로 바꿔"
    ↓
수정 완료 (30초)
    ↓
총 소요: 1분, ~100원 (API)
```

## 5. 비즈니스 모델

### 5.1 시장 가격 비교

| 서비스 | 웹에이전시 | 프리랜서 | **Homepage Exchange** |
|--------|------------|----------|----------------------|
| 랜딩 1페이지 | 100~300만원 | 50~150만원 | **30~50만원** |
| 메뉴/소개 추가 | +50~100만원 | +30~50만원 | **+10~20만원** |
| 전체 리뉴얼 | 300~1000만원 | 150~400만원 | **50~100만원** |

**포지셔닝:**
```
"에이전시의 30% 가격으로
 에이전시의 80% 퀄리티"

+ 유지보수 거의 무료
+ 수정 1분 내 완료
+ 호스팅비 0원
```

### 5.2 서비스 패키지

| 패키지 | 내용 | 가격 (1회성) |
|--------|------|--------------|
| **미니** | 랜딩 1페이지 + 연락처 | 30만원 |
| **기본** | 랜딩 + 메뉴 + 딥링크 (배민/쿠팡이츠) | 50만원 |
| **풀** | hoyadang.com 수준 전체 구현 | 80~100만원 |

### 5.3 유지보수 옵션

| 옵션 | 내용 | 월 비용 |
|------|------|---------|
| **셀프** | Claude Code 사용법 교육, 직접 관리 | 0원 |
| **서포트** | 월 2회 수정 요청 | 3만원 |
| **풀케어** | 무제한 수정 + 모니터링 | 5만원 |

### 5.4 핵심 셀링 포인트

**고객 대화 스크립트:**
```
"지금 워드프레스 월 얼마 내세요?"
→ "5천원~3만원이요"

"연간 6~36만원 + 외주비죠?"
→ "네..."

"저한테 50만원 한 번 주시면
 앞으로 호스팅비 0원,
 수정은 말로 하시면 됩니다"
```

**가치 제안 요약:**
| Before | After |
|--------|-------|
| 월 호스팅비 | → 0원 |
| 수정 외주비 (5~20만원/건) | → 말로 요청 |
| 수정 대기 (3~7일) | → 1분 |
| 보안 취약점 | → 정적 사이트, 해킹 불가 |

# .github/workflows/pages.yml (필요시)
name: Deploy to GitHub Pages
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/configure-pages@v4
      - uses: actions/upload-pages-artifact@v3
        with:
          path: '.'
